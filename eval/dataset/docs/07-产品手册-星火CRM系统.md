# 星火 CRM 客户管理系统产品手册

**产品型号：XH-CRM-S3 | 文档版本：V3.7 | 更新日期：2026-07-01**

## 第一章 产品概述

星火 CRM（XH-CRM-S3）是面向销售团队与客户成功团队的客户全生命周期管理系统，覆盖线索、商机、合同、回款、售后五大环节。与星火 OA（XH-OA-Pro）深度集成，审批与合同数据互通。

## 第二章 核心功能

### 2.1 线索管理

支持多渠道线索接入（官网表单、广告投放、展会扫码），线索自动查重与评分（基于 30+ 维度模型），高分线索自动分配给销售。

### 2.2 商机管理

销售漏斗可视化，支持自定义阶段（默认七阶段：初步接洽→需求确认→方案演示→报价→商务谈判→合同评审→赢单）。商机预计金额与赢单率可预测月度业绩。

### 2.3 回款管理

合同回款计划自动生成，逾期 7 天自动提醒销售与财务，逾期 30 天升级至销售总监。

## 第三章 版本与价格

| 版本 | 席位数 | 价格 |
|---|---|---|
| 创业版 | 10 席以内 | 免费 |
| 成长版 | 10—100 席 | 5000 元/年 |
| 专业版 | 100—500 席 | 20000 元/年 |
| 旗舰版 | 不限 | 50000 元/年 |

专业版及以上支持 API 开放平台与自定义报表（BI 引擎）。

## 第四章 与其他产品的关系

- CRM 与 OA 的客户档案、合同审批数据双向同步，需在两边同时开通"数据互通"开关。
- CRM 与财务系统（星火财云 XH-FC-1）集成仅限专业版及以上。
- 注意：CRM 系统的免费创业版不含 API 开放平台，如需对接自研系统请购买成长版及以上。

## 第五章 常见问题

**Q：CRM 能对接微信公众号吗？**
A：成长版及以上支持微信公众号粉丝导入为线索，需企业认证服务号。

**Q：数据导出有限制吗？**
A：所有版本均支持 Excel 导出；每日导出上限：创业版 1000 条、成长版 10000 条、专业版及以上不限。

## 第六章 服务与支持

同 OA 产品，售后热线 400-800-1234。客户成功服务：专业版及以上配置专属客户成功经理（CSM），季度输出使用健康度报告。
